# Formal cards v3 — controlled closure, memory repair and operator calibration

**Audit date:** 2026-08-12

**Binding decision:** `V3_NO_SURVIVOR`

**Novelty admission:** none

V3 pivoted away from interpreting residual persistence as adaptation. These two cards preserve the strongest
mathematical reductions from the pivot. Neither card states a new theorem, and neither authorizes an experiment.

## Card V3-A — controlled state closure is predictive/process-state sufficiency

For a proposed state statistic `S_t=s(H_t)`, intervention sequence `u` and bounded test class `F`, v3 proposed

\[
\Delta_L(s;\mathcal U,\mathcal F)
=\sup_{\substack{h,h':s(h)=s(h')\\u\in\mathcal U,\,f\in\mathcal F}}
\left|\mathbb E[f(O_{t+L})\mid h,u]
-\mathbb E[f(O_{t+L})\mid h',u]\right|.
\]

This is a restricted distance between rows of the controlled system-dynamics matrix. A PSR uses entries
`P(test | history)` as state; exact closure means that histories merged by `s` have identical rows for every
declared action-conditional future test. Causal states use the analogous equality of conditional future laws.

The process-tensor operational Markov condition is the same controlled object in channel notation. For a fixed
second instrument `B`, it asks whether one stochastic channel `Lambda_B` satisfies

\[
\Phi_2^{(I,B)}=\Lambda_B[\Phi_1^{(I)}]
\quad\text{for every first instrument }I.
\]

For any data-processing divergence `D`, define `D_1` before `B`, `D_2` after `B`, and
`Delta_BF=D_2-D_1`. If the operational Markov condition holds, `Delta_BF<=0`; a positive value is therefore an
observable-level memory witness. Pollock et al. give the necessary-and-sufficient operational condition, and the
2026 SGD process-tensor paper already implements the two-step witness, confidence intervals and causal-break
diagnosis in machine learning.

### The requested repair is also occupied

For a classical history-memory-future split, finite Markov order is

\[
P(F,H\mid M)=P(F\mid M)P(H\mid M),
\qquad I(F:H\mid M)=0.
\]

Taranto et al. generalize this to instrument-specific processes. Their Theorem 1 bounds the error of a recovered
finite-memory process for a supported multi-time observable `C` by

\[
|\langle C\rangle_{\Upsilon}-\langle C\rangle_{\Lambda}|
\le |C|\sqrt{2\Theta(J_M)},
\]

where `Theta(J_M)` is operational memory strength. Thus the desired chain “controlled memory witness -> finite
memory repair -> task error bound” already exists, with the classical conditional-mutual-information construction
as its baseline.

Jiang et al. address the complementary representation-learning question directly. Given an imperfect state
function `f`, their PSR-f augments it with predictive tests; Theorem 2 gives minimal core sizes

\[
|T|=\operatorname{rank}(M)-\operatorname{rank}(f;M),
\quad
|H|=\operatorname{rank}(M)+\operatorname{rank}(f)-\operatorname{rank}(f;M),
\]

and Theorem 3 gives a consistent spectral completion under its core/rank conditions.

For continuous resolved variables, the Mori--Zwanzig Dyson identity yields the exact generalized Langevin split

\[
\dot{\hat\phi}_i(t)=M_i(\hat\Phi(t))
-\int_0^t K_i(\hat\Phi(t),t-s)\,ds+F_i(t),
\]

and data-driven work already learns the Markov and memory operators from reduced observations.

### Scope counterexamples

- A finite probe family is relative, not universal: a hidden branch can be triggered only by an unprobed action
  sequence while agreeing on every probed history/test. Failure to reject never certifies closure outside the
  declared instrument span.
- The same observed semigroup defect can be generated by non-unique hidden Markov realizations or memory kernels.
  It diagnoses inadequate closure but does not identify a unique physical missing state.

### Decision

C1 and C2 are `RETIRED_PRIOR_ART`. Their narrow operational interpretation is valid, but the certificate, repair
and error-control chain is already PSR/process-tensor/Markov-order/Mori--Zwanzig theory. A finance application may
use these tools; it cannot present them as a new NMI primitive or NCS method.

## Card V3-B — Poisson weighting cannot repair a missing state

For invariant laws `pi_P,pi_Q` and `(I-Q)h_Q=f-pi_Q f`, the exact perturbation identity

\[
(\pi_P-\pi_Q)f=\pi_P(P-Q)h_Q
\]

is standard Markov-chain Poisson perturbation. Its continuous-time generator form is the generator-comparison
method in Stein's method. The finite-time telescoping identity

\[
P^n-Q^n=\sum_{k=0}^{n-1}P^k(P-Q)Q^{n-1-k}
\]

is likewise standard. Learning a critic approximating `h_Q` creates a Stein/operator discrepancy; it does not make
the algebra new.

### Exact one-step and invariant-marginal blind spot

Let the true binary process be second-order:

\[
X_{t+1}=X_t\oplus X_{t-1}\oplus E_t,
\qquad E_t\sim\operatorname{Bernoulli}(\varepsilon),
\quad 0<\varepsilon<\tfrac12.
\]

The pair state `(X_{t-1},X_t)` is a four-state Markov chain with the uniform invariant law. Hence the observed
marginal is Bernoulli one-half and

\[
P(X_{t+1}=1\mid X_t)=\tfrac12.
\]

Its stationary one-step kernel and marginal therefore exactly match an iid Bernoulli chain. But

\[
P(X_{t+1}=X_t\oplus X_{t-1}\mid X_{t-1},X_t)=1-\varepsilon
\ne\tfrac12.
\]

Any objective using only the observed one-step kernel and invariant one-time law has zero discrepancy while the
multi-time process is wrong. In particular, every Poisson witness restricted to functions of `X_t` can report zero
stationary marginal bias. Higher-order tests or state completion are required, returning directly to Card V3-A.
This construction is elementary and is retained as a warning, not a new theorem.

### Decisive method coverage

- Glynn--Meyn Poisson theory and later computable perturbation work control invariant-law sensitivity through
  solutions of the Poisson equation.
- Stein generator comparison already rewrites distribution error as an expected generator difference evaluated on
  a Poisson/Stein solution.
- Kostic et al. provide high-probability operator-power bounds uniform over arbitrarily long horizons for ergodic
  Markov systems.
- Invariant-measure neural operators and DySLIM already regularize dynamics learning against long-run
  distributions, alongside pointwise objectives.

### Decision

C3 is `RETIRED_PRIOR_ART`. A controlled partial-observation implementation would combine existing closure tests
with existing Poisson/Stein and Koopman objectives. V3 found no new assumption, identity, estimator or bound that
is unavailable by direct composition. Because no formal survivor remained, exp146 was not preregistered or run.
