## 1. Frozen question

For a stateful hard-event system observed through event batches with a declared partial order, can one compute or
learn a calibrated, non-vacuous set of outcome or intervention responses over all legal event orders, with a
new tractability boundary and without inventing a total order?

Let

\[
S_{k+1}=K_{e_k,u}(S_k,\xi_k),
\qquad P_b=(E_b,\prec_b),
\qquad \pi\in\mathcal L(P_b),
\]

and define

\[
\Psi_u(P_b,s)=
\left\{
\mathbb E[f(K_{\pi,u}(s,\xi))]:\pi\in\mathcal L(P_b)
\right\}.
\]

Every precedence edge, event grouping, actor/channel label and intervention must be anchored in an external feed
or rule contract. Hidden simulator labels cannot define the ordering semantics.

## 4. Baselines that cannot pass T0

The following must be derived or cited, then excluded from the novelty claim:

1. any two linear extensions of a finite poset are connected by adjacent swaps of incomparable elements;
2. if every reachable adjacent incomparable update pair commutes for the declared property, that property is
   invariant across legal orders;
3. for two events, the scalar order effect is exactly
   \(f(K_{e'}K_e s)-f(K_eK_{e'}s)\);
4. enumerating, sampling or learning a distribution over linear extensions;
5. standard partial-order reduction using independence/commutativity;
6. Lie--Trotter/Strang commutator error bounds;
7. standard interval-censored Hawkes or neural point-process likelihoods;
8. standard treewidth dynamic programming, including known FPT and hardness results for counting linear
   extensions.

## 5. Toy semantics audit

Use a finite price--time queue with persistent order identities and exact integer quantities. The mandatory event
families are add, partial cancel, full cancel and execution. The poset must encode lifecycle precedence and leave
only genuinely unresolved pairs incomparable.

Four cases are required:

1. disjoint-resource events that commute;
2. cancel and execute events targeting the same resting order, including enabledness after each ordering;
3. an add and an aggressive execution whose order changes the filled identity or remaining queue;
4. multiple visible executions generated by one marketable order, where atomic grouping prevents a false
   uncertainty set.

T0 must show an arbitrary deterministic tie policy can produce a point answer outside another legal ordering's
answer. This is a sanity check, not a theorem.

## 6. Eligible exits

### E1 — semantic-conflict algorithm and matching boundary

Specify an exact extremal, expectation or witness problem over \(\Psi_u\). Give an algorithm whose complexity is
controlled by a declared semantic-conflict parameter and prove a matching hardness, lower bound or approximation
boundary.

E1 fails if the algorithm is enumeration, ordinary partial-order reduction, a standard linear-extension dynamic
program, or an immediate application of a known bounded-treewidth theorem.

### E2 — calibrated learned response set

For a declared finite or stochastic transition class, give a computable set \(\widehat\Psi_u\) with a uniform
finite-sample coverage statement that includes both transition estimation and legal-order uncertainty. Provide a
non-vacuity condition and a matching lower bound or rate.

E2 fails if coverage is a union bound/conformal wrapper over enumerated orders, requires the unknown true order
law, or omits state-dependent enabledness.

### E3 — property-specific abstaining certificate

Give a certificate that either proves every legal order produces the same declared decision or returns a minimal
order-conflict witness, with a complexity or statistical guarantee not implied by property-preserving
partial-order reduction.

E3 fails if it is trace equivalence, reachability/model checking under a renamed property, or a generic
commutator threshold.

T0 needs at least one of E1--E3 to survive both proof audit and exact nearest-work reduction. The elementary
commutation theorem cannot count as the survivor.

## 7. Conditional metadata gate

Only after one exit survives may T0 inspect source contracts. All conditions must hold:

- one market source has authoritative sequence or packet identifiers and persistent event identity;
- a deterministic coarsening operator can remove ordering information without changing event contents;
- one independent feed has genuinely coarser order semantics rather than merely rounded displayed timestamps;
- one non-financial event system supports the same exact-to-coarsened construction;
- licences permit the intended reproducible analysis;
- event grouping distinguishes a single action split into multiple feed messages from truly distinct uncertain
  actions.

No numerical market outcome may be read during this gate.

## 8. Verdict rule

T0 is PASS only if:

1. at least one of E1--E3 is written as a precise theorem/algorithm with assumptions, guarantee and proof;
2. no primary-work reduction recovers the same result;
3. the toy system distinguishes the method from every frozen baseline;
4. the conditional metadata gate passes in full;
5. an independent reviewer can state the contribution without using “first in markets,” “MD-inspired,” or a
   conjunction of existing components.

Otherwise T0 is FAIL/RED and the route closes before implementation or outcomes. A PASS authorizes only a
separate, preregistered exact-to-coarsened benchmark gate on CPU.
