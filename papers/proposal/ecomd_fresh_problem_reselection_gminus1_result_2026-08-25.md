# EcoMD fresh-problem reselection: G-1 result

**Date:** 2026-08-25
**Decision:** no newly screened route is activated. One program-and-trace market-agent route is retained as a conditional D-1 reserve; nineteen alternatives are failed-closed before outcomes, implementation, data acquisition, EcoMD training, or GPU use. The pre-existing verification-liquidity route remains active, the FCC card remains a candidate, and DCRDEX remains parked; none was re-audited in this screen.

## Decision rule

The screen searched for a falsifiable market-dynamics problem that could plausibly support a *Nature Machine Intelligence* or *Nature Computational Science* paper while preserving the useful EcoMD viewpoint: stateful many-body dynamics, path laws, perturbation response, and external validation beyond one simulator. A route could become active only if its hostile, outcome-blind estimate of surviving T0 was at least 15%, its central claim was not a renaming of an established problem, and a versioned data or benchmark contract could identify the target.

No card met all three conditions. The result is therefore a reselection decision, not a positive scientific result.

## Selected conditional reserve

The only residual from this screen worth a bounded contract audit is:

> Given a frozen agent program, a small number of traces from seen mechanisms, an unseen market-mechanism specification, the initial state and an opponent population, predict a calibrated joint law for the agent and market trajectories before deployment.

For agent program \(P_i^v\), observations \(D_i^{\mathrm{seen}}\), unseen mechanism \(M^*\), opponents \(\Pi_{-i}\), and initial state \(x_0\), the target is

\[
\widehat Q\!\left(\tau_i,\tau_{\mathrm{market}}\mid
P_i^v,D_i^{\mathrm{seen}},M^*,\Pi_{-i},x_0\right).
\]

For a version upgrade, the actual program diff \(\Delta P_i^{v\rightarrow v+1}\) must also be supplied. The paper-level object is a calibrated path law with abstention for preregistered risks, not mean score, next-action accuracy, or an unrestricted claim to predict arbitrary programs.

### What would make the claim nontrivial

All of the following would be required:

1. author-held-out agents and mechanism-family-held-out transfer;
2. source plus traces outperforming trajectory-only theory-of-mind, source-only execution prediction, an equal-cost real-rollout baseline, edit distance, and a generic language model;
3. calibrated coverage or explicit abstention for frozen market-risk functionals;
4. invariance to semantics-preserving refactors and sensitivity to a one-line behavior-changing diff;
5. a chronological prediction of a real, held-out program upgrade;
6. replication in a second independently maintained market system;
7. an outcome-free precision/power calculation that determines the required author count rather than treating 20 as statistically sufficient;
8. a training-data contamination audit or prospectively sealed unpublished programs, so an author-held-out program is genuinely unseen;
9. rollout-baseline accounting that includes data generation, model training and amortized inference rather than manipulating only marginal test-time cost.

### Why it is not active

The public benchmark contract presently fails. The relevant unit is a rectangular intersection of externally authored programs across mechanisms,

\[
\left|A_{M_1}\cap A_{M_2}\cap A_{M_3}\right|\ge 20,
\]

not a sum over different agents, years, or incompatible contests.

| System | Public program supply | Same programs across at least three genuine mechanisms | Frozen execution lineage | Verdict |
|---|---|---|---|---|
| SCML | The live contributed-agent repository exposes many historical source artifacts, but this screen did not freeze an author-level census | Standard and OneShot are related modern games but use different agent base classes and AWIs; this screen did not establish an intersection of identical unedited programs, and discontinued Collusion is not a clean third mechanism ([official documentation](https://scml.readthedocs.io/en/stable/tutorials/01.run_scml2020.html)) | Historical compatibility edits do not preserve original containers, dependencies, model snapshots, prompts, and RNG lineage | Fail; closest reopening target |
| Power TAC | Server and log infrastructure are strong, but externally authored broker source is not a complete public registry | Wholesale, tariff, and balancing modules form one integrated game rather than three alternative mechanisms | Broker source, dependencies, and per-program reuse rights are incomplete | Fail |
| TAC SCM and older TAC domains | Many historical entries exist | APIs differ across domains; a same-program intersection is unverified | Much of the record is binary or log-only and lacks containers and clear reuse rights | Fail |
| ABIDES | Many runs can be generated from a small set of organizer classes | The main public environment is a continuous double auction; parameter changes are not three mechanism families | No qualifying census of independent external programs or upgrade lineage | Fail |

Among these four audited platforms, this screen established no qualifying public contract. Current outcome-blind estimates are **8--12% for T0** and **2--4% for a complete NMI result**. With organizer cooperation that freezes at least 20, preferably 50, independently authored programs with containers, dependencies, model/prompt snapshots and RNG, executes them prospectively through three shared-interface genuine mechanisms, and supplies a second-system replication, the estimates rise to **18--25% for T0** and **6--10% for NMI**. The final author count would still be set by an outcome-free precision/power calculation.

## Closest prior-art modules

No single primary work found in this screen exactly combines versioned program source, few behavioral traces, author-held-out and mechanism-family-held-out calibrated market path laws, and chronological prediction of a real code change. The components are nevertheless crowded:

- few-trace inference for unseen agents or policies: [ToMnet](https://proceedings.mlr.press/v80/rabinowitz18a.html), [GIGO-ToM](https://arxiv.org/abs/2412.04367), [Subgoal Inference at NeurIPS 2024](https://papers.nips.cc/paper_files/paper/2024/hash/6fb9ea5197c0b8ece8a64220fb82cdfe-Abstract-Conference.html), and [OEOM at AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34488);
- policy-conditioned out-of-distribution dynamics: [Policy-Conditioned Environment Models](https://mlanthology.org/icml/2024/chen2024icml-policyconditioned/) and [WebEvolver](https://aclanthology.org/2025.emnlp-main.454/);
- source-and-trace behavior prediction: [CRUXEval](https://arxiv.org/abs/2401.03065), [CodeFlow](https://arxiv.org/abs/2408.02816), [PredEx](https://doi.org/10.1145/3729402), and [SURGE](https://aclanthology.org/2025.emnlp-main.162/);
- code-change and predeployment forecasting: [Neural Change Prediction](https://arxiv.org/abs/2606.03378), [Behavioral Co-Versioning](https://arxiv.org/abs/2604.16933), [FOREAGENT](https://arxiv.org/abs/2601.05930), [InferAct](https://arxiv.org/abs/2407.11843), and [OpenAI Deployment Simulation](https://openai.com/index/deployment-simulation/).

OpenAI Deployment Simulation is the strongest headline collision: broad claims of first predicting post-release agent behavior are unavailable. The residual would have to be specifically about program-conditioned transfer across market mechanisms with calibrated joint path risk.

The route also faces a structural trilemma. If every program, dependency, opponent, mechanism and random seed is known and executable, the real simulator is an oracle and the learned model is a surrogate. If a future change is not supplied, the new behavior is not identified. If its diff is supplied, the task approaches predictive execution and neural change prediction. Only a demonstrated cross-mechanism semantic-transfer and risk-coverage result could escape this reduction.

## Mandatory kill tests for the reserve

- **Unseen trigger:** two programs agree on every observed trace but diverge on a branch activated only by the new mechanism.
- **Refactor invariance:** variable renaming, dead-code insertion, and a semantics-preserving refactor must not change the prediction.
- **One-line cascade:** changing a liquidation comparison from `>=` to `>` may create a macroscopic path-law change despite a tiny textual diff.
- **Hidden dependency:** equal visible source can diverge under a different model snapshot, API, environment variable, clock, or RNG implementation.
- **Rare hazard:** a few traces cannot certify a \(10^{-6}\) failure probability without structural assumptions; the method must abstain.
- **Opponent dependence:** the focal agent's market path is not identified without opponent programs or a frozen opponent distribution.
- **Unrestricted-program impossibility:** sound non-vacuous certification for arbitrary Turing-complete agents is obstructed by Rice/halting arguments; the language, calls, horizon, and resource limits must be explicit.

The missing public 20-by-3 matrix is the reason for parking the route, not by itself a second closure decision. D-1 permits only one bounded organizer/registry contract audit, after separately authorized external outreach. The route becomes failed-closed if an organizer confirms that the matrix, unedited third mechanism, execution lineage, reuse rights, chronological upgrade, or independent replication cannot be supplied, or if a complete census shows no credible supply path. No model implementation is authorized before every activation gate passes.

### Tempting renamings that are also closed

**Market-event hyperuniformity, giant number fluctuations, and spectral rigidity.** After projecting away exact inventory conservation, seasonality, clock choice, and Hawkes/Cox clustering, the strongest residual had T0 8--12%, NCS 2--5%, and NMI 1--3%. The object is the Bartlett spectrum, already covered by Hawkes covariance and spectral estimation. Stable queues create an exact false positive: if additions \(A\), removals \(D\), and inventory \(Q\) satisfy

\[
A(T)-D(T)=Q(T)-Q(0),
\]

stationary \(Q\) forces a zero-frequency net-flow mode even when \(A\) and \(D\) are clustered. Conversely, identical event spectra can act on deep or best-price queues and yield opposite price responses. Relevant precedents include [Bacry--Muzy](https://doi.org/10.1109/TIT.2016.2533397), [Cheysson--Lang](https://doi.org/10.1214/22-AOS2173), [Hardiman--Bercot--Bouchaud](https://doi.org/10.1140/epjb/e2013-40107-3), and [Tóth et al.](https://doi.org/10.1103/PhysRevX.1.021006). This card is failed-closed rather than renamed.

**Natural blockchain fork twins.** Ethereum exposes some losing-root and reorganization metadata but not a guaranteed permanent public archive of every losing execution payload, transaction, receipt, and post-state. Solana's public historical interface is rooted/confirmed rather than fork-addressable. Given a complete payload, EVM/SVM transition prediction is deterministic replay; without it, private bundles make the target nonidentified. Natural fork labels are also endogenous and losing branches stop receiving adaptive flow. T0 is 3--7% and complete NCS 0.5--1.5%. [State Twins](https://arxiv.org/abs/2605.11522), transaction-permutation, MEV, and blockchain-digital-twin work occupy the nearest residual. The route is failed-closed until two ecosystems publish complete, licensed, root-verifiable noncanonical histories at preregistered scale.

## Resource and integrity boundary

This was an outcome-blind G-1 screen. It did not open embargoed verification-liquidity outcomes, query candidate outcome records, download datasets, train a model, modify EcoMD, or use a GPU. The active verification-liquidity transport route remains unchanged and separate. Subject to separate authorization for any external inquiry, the selected reserve's D-1 scope is limited to written organizer/schema/licence confirmation and an immutable program-by-mechanism census.
