## Corrected theory boundary

Lemma 1 from the historical C2 note survives only as an M0 lumpability theorem. It applies when
future request intensities ignore allocation identity and all identity-level economic states. Once
cash, inventory, induced value or learning feeds back, anonymous paths need not be invariant even
without forward-looking strategy.

The historical threshold-depth lemma survives as one model-specific comparative static for unit
orders. It cannot determine the sign of the full strategic class. Angel--Weaver and subsequent
pro-rata work provide a separate size-competition channel, while current queue-uncertainty theory
can produce excessive or fleeting depth. Module B therefore has no preregistered universal depth
sign.

The new load-bearing theorem is intentionally narrower. In the isolated race, all units arrive
before demand and have one common price. Random-unit allocation makes each unit's execution chance
independent of latency effort; FIFO does not. This directly identifies the value of queue rank and
supports a directional primary contrast without pretending to solve general LOB equilibrium.
