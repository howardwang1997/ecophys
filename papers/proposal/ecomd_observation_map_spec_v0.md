# EcoMD external-observation map v0: field audit and support boundary

**Frozen:** 2026-08-10
**Parent gate:** F1 in `plan_v4a_simulator_audit_release.md`; formerly G3 in Plan v4
**Audited code:** `cfe06a79e4215cd0092d999ca13b2cc228bdda57`
**Current decision:** **FAIL for real message/order-level mapping; synthetic aggregate plumbing only**
**Recommended recoverable scope:** aggregate events and fixed-time-bin observables

## 1. Why this document exists

An observation operator is not a convenient rename of a latent. It must specify a probability law from a
state-complete simulator path to quantities with the same definition, units, clock and support as the data.
The existing EcoMD adapters passed synthetic reconstruction and misspecification tests, but those tests used
messages generated by their own declared family. This audit asks the prior question: what external data can the
current model actually claim to generate?

The answer is narrow. EcoMD currently generates continuous agent-state changes and an internal scalar price
process. `EcoMDL2Adapter` separately generates one stylized aggregate queue message per EcoMD step. Its book
price does not use EcoMD's price, its message clock has no fitted intensity, its sizes have no market unit, and
its IDs are event counters rather than order identities. It is a valid synthetic interface fixture. It is not a
likelihood for real LOBSTER messages and cannot support order-level or matching-engine language.

## 2. Source quantities in EcoMD

For transition `t -> t+1`, let `Delta x_i,t = s_i,t+1[0] - s_i,t[0]`. The default excess-demand price module
exposes:

| EcoMD quantity | Definition | Native unit/support | What it is not |
|---|---|---|---|
| `s_i[0]` | designated continuous agent position coordinate | model coordinate; real valued | an exchange order, account holding or queue position |
| `latent_flow_alignment_t` | `sum_i Delta x_i,t / (sum_i abs(Delta x_i,t) + eps)` | dimensionless, `[-1,1]` | CKS OFI, signed trade flow or queue imbalance |
| `volume_t` | `sum_i abs(Delta x_i,t)` unless a configured alternative is used | positive model units | shares/contracts traded or message size |
| `excess_demand_t` | scaled aggregate position change, possibly normalized/augmented/concave-transformed | model units; configuration dependent | observed net order flow unless an emission model is validated |
| `log_return_t` | internal price-module increment including price noise and optional mechanisms | dimensionless log return per simulator step | an L2 mid-price change without a time/tick measurement equation |
| `log_price_t` | cumulative internal log price, initialized by configuration | relative model log-price level | dollars or integer ticks |
| `volatility_t` | EWMA of absolute internal returns | model return per simulator step | a directly observed volatility state |
| `h_*`, force and cache fields | hidden dynamic memory required for continuation | latent tensors | external observables |

Only the complete `SimulatorState` determines the next transition. An observation operator may condition on
the state or transition, but must never expose hidden fields as if they were measured data.

## 3. External LOBSTER quantities

The tracked external parser reads:

| External field | Vendor-level meaning used here | Unit/support |
|---|---|---|
| `time` | seconds after midnight; raw row order resolves equal timestamps | float seconds, nondecreasing before declared tie policy |
| `event_type` | submission, partial cancellation, deletion, visible execution or hidden execution | integer 1--5 in the frozen samples |
| `order_id` | identity defined by the order-level feed | positive integer with cross-event lifecycle semantics |
| `size` | submitted, removed or executed quantity | integer shares/contracts |
| `price` | message price | dollars after ingest; vendor integer divided by 10,000 |
| `direction` | buy-limit side `+1`, sell-limit side `-1`; execution aggressor sign is derived from executed-limit side | `{-1,+1}` |
| order-book row | displayed aggregate depth after the corresponding message | dollars and integer size at each level |

The six-mark point-process projection in exp138 deliberately discards order identity and merges cancellation
types. That projection supports aggregate mark/intensity claims only; it cannot recover individual-order
priority.

## 4. Current adapter audit

`EcoMDL2Adapter.emit` currently implements the following map:

| Output field | Current rule | External equivalence | Verdict |
|---|---|---|---|
| event count | exactly one emitted event per EcoMD transition | real counts are irregular, state/history dependent and strongly intraday | **unsupported** |
| time | `(absolute_step + 1) * dt` | `dt` has no fitted seconds-per-step calibration; no equal-time groups | **unsupported** |
| side/pressure | Bernoulli logistic in current `latent_flow_alignment`; sign fixed by positive excess-demand convention | structural model sign is not an empirical sign validation | synthetic only |
| event type | fixed add probability; fixed removal-type probabilities; optional hidden event | real mark probabilities depend on queue, time, asset and history | synthetic only |
| level | fixed exponential level law | no tick/spread/queue-state calibration | synthetic only |
| size | `1 + Poisson(exp(log_mu + gamma*abs(latent)))` | no conversion from model position units to shares/contracts | **unsupported** |
| price | selected from a separately initialized adapter book | independent of EcoMD `log_price` and `log_return` | **contradiction** |
| book | aggregate queue updated by stylized add/remove rules | no inside-spread placement, variable spread, real reset law or price-time priority | synthetic aggregate only |
| `order_id` | a new consecutive integer for every event | cancellations/deletions/executions do not reference an existing order | **not an order ID** |
| hidden event | type 5 leaves displayed book unchanged | useful aggregate convention, but no trade record or hidden-liquidity model | partial aggregate support |

`DynamicL2Generator` adds queue depletion and price moves, but its latent is an exogenous AR path rather than a
state-complete EcoMD path. Its mid-price reset remains independent of EcoMD's internal price. Exp137 therefore
validates a dynamic synthetic evaluator, not the missing EcoMD price/message coupling.

## 5. Four distinct support levels

Claims must use exactly one support label:

1. **`synthetic_fixture`.** Self-generated messages used to test reconstruction, fitting, controls and resume.
2. **`aggregate_bin`.** Fixed-time-bin returns, executed volume, message counts and aggregate L1/L2 features.
3. **`aggregate_event`.** Event times, six aggregate marks, sizes/prices and displayed-book transitions after
   order identity has been explicitly discarded.
4. **`individual_order`.** Full add/cancel/delete/execute lifecycle, order identity, price-time priority and
   matching-engine semantics.

Current EcoMD code supports level 1. A defensible v1 can target levels 2 and, conditionally, 3. Level 4 requires
a new order-level agent action space and matching engine; it cannot be obtained by renaming consecutive event
counters.

## 6. Recommended v1 observation hierarchy

### 6.1 Primary: aggregate-bin measurement model

Freeze a physical bin width `Delta` in seconds. One EcoMD macro transition represents one bin only after a
declared time-scale parameter maps simulator steps to `Delta`. For bin `t`, the observation vector is

`Y_t = (Delta log mid_t, log(1 + executed_volume_t), mark_counts_t, L1/L2 summaries_t)`.

The measurement model may use EcoMD transition summaries as predictors:

- `log_return_t` predicts the binned mid return through an explicit location/scale equation;
- `log(1 + volume_t)` predicts binned executed volume through a positive affine or count model;
- `latent_flow_alignment_t` is an optional latent predictor of signed aggregate flow, never an equality to OFI;
- pre-bin observed queue/history features enter an observation-only baseline and any combined model.

Every scale, offset and noise parameter is fitted on training data only. Identifiability is reported jointly:
for example, multiplying latent volume by a constant and dividing its measurement slope is a gauge unless one
scale is fixed. The scientific unit is a day/market panel, not individual messages within a day.

### 6.2 Secondary: aggregate-event marked point process

Within a bin, a conditional count/intensity model may emit `K_t` events rather than forcing `K_t=1`. Each event
uses the six exp138 aggregate marks and a displayed-book state. Required semantics are:

- event intensity depends on the current/past latent bin state and pre-event observed history only;
- mark, level and size laws are conditional and normalized; no invalid queue removal is emitted;
- `event_id` replaces fake `order_id`; external order IDs are dropped before comparison;
- emitted book mid and EcoMD internal price are connected by one declared measurement equation, or the EcoMD
  internal price is excluded from the scored observables. Two independent price processes are forbidden;
- timestamp ties follow a declared representation; a simple point-process likelihood may not silently treat
  sequential equal-time rows as independent positive intervals;
- the output is labeled `aggregate_event`, never an exchange simulator.

### 6.3 Unsupported: direct individual-order emission

An individual-order claim would require persistent outstanding orders, ownership, partial fills, amend/cancel
references, queue priority, exchange-specific matching, tick/lot rules and event-to-agent attribution. None of
these are in `SimulatorState` or the current adapters. This route is closed unless those mechanisms are added
and independently audited.

## 7. Price consistency choices

Exactly one of these choices must be frozen before implementation:

| Choice | Rule | Cost/limitation |
|---|---|---|
| P1 efficient-price measurement | EcoMD `log_price` is a latent efficient price; displayed mid is its tick-rounded noisy measurement and queue moves must remain consistent with it | requires an explicit microstructure-error law and can create forced depletion events |
| P2 book-generated observed price | aggregate events generate the displayed mid; EcoMD internal price is not independently scored and only latent state/flow conditions emissions | sacrifices the current price-module claim and requires careful feedback if price affects future state |
| P3 aggregate-bin only | compare binned EcoMD returns to binned market mid returns; no message path is claimed to reproduce the exact EcoMD price transition | weakest but immediately defensible primary route |

The recommended initial route is **P3**. P1/P2 remain research options; neither may be selected after viewing
real held-out performance.

## 8. Causal timing and latent inference

For a real-data likelihood, the EcoMD latent path is not observed. The current repository lacks a frozen
filtering/inference protocol that produces `latent_flow_alignment_t` from past observations. A valid comparison
must choose one of:

- unconditional simulation calibrated only on training-period aggregate distributions;
- a causal filter with posterior/predictive states using observations strictly before the scored bin/event;
- simulation-based likelihood-free calibration with time-separated training and final evaluation.

Running EcoMD with a seed and pairing its latent path to an unrelated real message row is invalid. Optimizing a
latent path using the same held-out outcomes later scored is lookahead. The observation-only baseline must see
the same past external history as the combined model, and all latent-selection/tuning must finish before the
test split is opened.

## 9. Identifiability ledger

| Ambiguity | Consequence | Required control |
|---|---|---|
| latent sign gauge | `z,beta` and `-z,-beta` can have identical likelihood | structural sign fixed before fitting plus sign-flipped negative control; do not call it empirically verified |
| latent scale gauge | position/volume scale trades against emission slope | fix one scale or report equivalence class/profile likelihood |
| time-scale gauge | simulator `dt`, event intensity and Hawkes decay can compensate | fix seconds-per-step before test or identify from independent training target |
| price-level gauge | relative EcoMD log price lacks dollar/tick origin | score returns or fix origin/tick using training metadata only |
| observation-history confounding | autocorrelated latent can proxy queue/Hawkes history | strongest observation-only, lag, shift and permutation baselines |
| state/parameter non-identifiability | different hidden states can produce the same aggregates | report predictive equivalence; do not claim recovered agents |
| market/day dependence | one day produces millions of correlated events but one independent panel | hierarchical day/market statistics; no event-level pseudoreplication |

## 10. Binding decision and next gate

1. The current `EcoMDL2Adapter` remains available as a `synthetic_fixture`; its class/result names do not imply
   external validity.
2. F1/G3 is **not passed**. The current map fails price, clock, size-unit and order-identity equivalence.
3. The next experiment must test a machine-readable support contract on generated paths. It must deliberately
   inject dual-price, wrong-clock, fake-order-ID, sign-flip and observation-only cases and verify that unsupported
   claims fail before likelihood fitting.
4. The first implementable scientific route is `aggregate_bin` with price choice P3. An `aggregate_event`
   extension is allowed only after the base contract passes and uses `event_id`, conditional intensity and one
   consistent price process.
5. No paid data, unseen real test or GPU production run is required for this gate. Estimated cost is below two
   CPU core-hours locally; the V100 hosts may be used as CPU workers if needed.
6. A later real confirmation requires genuinely unseen days/markets. Exp138's exposed test portions remain
   development evidence and cannot be relabeled.

## 11. Exp142 enforcement outcome

Exp142 was preregistered at commit `021d0b0b`, implemented at clean commit `44daf531`, and formally run once.
All nine gates passed. The three scoped declarations had their exact expected reports, all twelve isolated
semantic defects returned their frozen single error, and invalid fit callbacks ran zero times. The formal
adapter probe emitted 256 rows for 256 steps; all 256 IDs were new consecutive event counters, and none of 132
removal/execution rows referenced an earlier ID.

This PASS does not reverse the field-audit FAIL. It makes the support boundary executable: the current adapter
is accepted only as `synthetic_fixture`, while `aggregate_bin` + P3 is accepted as a prospective declaration.
The then-pending measurement implementation was delegated to exp143. Result:
`experiments/142_observation_semantic_contract/RESULTS.md`.

## 12. Exp143 aggregate-bin P3 outcome

Exp143 was preregistered at commit `6d56a0b4`, implemented at clean commit `2b54170e`, and formally run once.
All ten gates passed. The runner reconstructed 4,096 bins from 104,160 generated aggregate rows, including
14,268 timestamp ties. Six-mark counts and executed share volume were exact; maximum return error against the
independent generated reference was `1.70e-16`; monolithic/chunk/checkpoint outputs were bit-exact.

The train-only fit was unchanged byte-for-byte after every held-out response was corrupted, while a training
perturbation changed its hash. In the self-generated control only, latent/observation-only RMSE ratios were
0.313 (return) and 0.437 (log volume), directional gain was 0.100 nats/event, and the anchored sign beat the
unrefitted flipped sign by 0.457 nats/event. These are correct-specification plumbing values, not empirical
market results. The factor-seven gauge passed and the fit serializes
`COEFFICIENTS_CONDITIONAL_ON_FROZEN_LATENT_SCALE`.

F1 is now PASS only for the synthetic implementation/semantics of `aggregate_bin` + P3 under unconditional
train-calibrated simulation. `aggregate_event` and `individual_order` support remain FAIL, and any real
predictive claim remains entirely gated by F4 on genuinely unseen panels. Result:
`experiments/143_aggregate_bin_p3/RESULTS.md`.
