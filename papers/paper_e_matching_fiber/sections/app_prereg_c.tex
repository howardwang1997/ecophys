\subsection{Freeze mechanics}
\label{app:prereg-freeze}

The D0 freeze hash is computed by the PI in the D0 freeze session (or by a
PI-directed freeze agent in that same session, recorded as such), using
\texttt{sha256} over the exact file bytes of the frozen file list. The hash
chain covers, at minimum: preregistration v2; the statistical contract as
amended (clauses C1--C16, gates G1--G12); the theory appendix; the
experiment plan; the D-2 evidence map; the D-1 session companions including
the lemma-writeups manifest; the enriched-fixture manifest; the K-preflight
results; the fiber-resampler statement; the DGP generator and config; the
seed/stream manifest; the estimator hashes; the analyzer contract; and the
ops plan --- together with the hash-locked archive, these constitute the
freeze record. Recording then proceeds in mandatory order, and a failure at
any step stops the freeze (no partial freeze): (i) git commit of exactly the
frozen file set on the integration branch (branch name recorded in the
freeze log; commit
\texttt{sha256} recorded); (ii) upload of the freeze record (per-file hashes
$+$ commit hash $+$ freeze timestamp) to the immutable R2 object
\texttt{r2://[bucket anonymized for review]/alpha\_cube\_d0\_20260919/freeze\_record.json};
(iii) entry in the D0 session log with the R2 object etag.

\paragraph{Known-typo policy.}
Known-stale lines inside incorporated companions (including the elided
bundle-anchor typo \texttt{fea8b136...9581c}) are \emph{not} edited
pre-freeze; the preregistration records the canonical 64-hex anchor, and the
freeze record binds those companions by their own per-file hashes.
String-matching auditors are directed to the errata register of
\S\ref{app:prereg-errata}.

\subsection{Post-freeze edit policy}
\label{app:prereg-edits}

After the D0 freeze the \emph{only} permitted edits to the preregistration
and the frozen contract are: (1) finite-instance corollaries of
already-frozen statements; (2) constants polishing (no change of form,
reference convention, or scope); (3) enumeration of realized results against
the preregistered targets. Prohibited after freeze: any new confirmatory
proposition; any endpoint, estimator, threshold, cell, seed, axis, horizon,
family, schema, or record-count definition change; any analyzer rerun; any
outcome-dependent analysis of any kind. Any breach is STOP-class with no
repair (Section~\ref{sec:scope-stop}).
