# OASIS simultaneous-window random-priority network response

On 2026-08-24 the outcome-blind D−1 closed this route before any transaction record, support count, parser, replay
or effect analysis. MISO and SPP rules do randomize tied customer order and turn that order into round-robin TSR
evaluation positions; BPA is a similar backup. The rule gate therefore passed.

The current public machine contract did not pass. Standard OASIS fields include assignment reference, customer and
service variables, priority, bid/pre-confirmation, requested and granted capacity, POR/POD, status and ordinary
queue/update timestamps. They do not document a stable SSW run, realized customer lottery order, lottery round or
derived TSR evaluation position. Authenticated UI material may display a lottery-order concept, but OATI prohibits
automated UI scraping and no supported historical machine export or research-reuse contract for it was found.
Ordinary queue time, status time and assignment-reference order are forbidden proxies.

The network-state contract failed independently. AFC/ASTFC horizon, flowgate summary and request-evaluation reports
do not establish an immutable, versioned AREF-to-immediate-pre/post-state join containing the full flowgate vector,
topology/outage inputs, impacts, counteroffer trace and interleaved updates. Request status and granted MW are not
the network post-state. Federal audit-retention rules do not prove that the internal lottery or calculation state
is an exported audit variable.

MISO and SPP are distinct networks but share the OATI webTrans product family and essentially the same allocation
workflow. They can support cross-network replication only, not independent software or mechanism replication.
The true assignment unit is a customer permutation followed by round-robin requests, so request ranks are dependent
and any later inference must operate at the window/customer-permutation level.

Even with hypothetical complete private data, the immediate response is random-order online multidimensional
packing: earlier accepted requests reduce residual flowgate capacity and shrink later feasibility. Connection-order
hosting-capacity path dependence and interference inference already occupy the neighboring science. No exact OASIS
SSW empirical paper was found in a partial 18-work hostile audit, but that narrow application gap is not a Nature
method. Current review priors are about 3% for rescuing the frozen public contract and 8--10% novelty survival
conditional on complete data, or about 0.3% jointly.

Reopen only on versioned, field-level written confirmation from both MISO and SPP/OATI of a supported machine
export for the SSW/customer/round/request order, the complete eligible set and assignment probabilities, atomic
versioned pre/post AFC state, and explicit historical access, automation and publication rights. A new outcome-blind
freeze must then pass at least 50 admissible multi-constraint lotteries per operator and 200 combined. Any claim of
implementation independence additionally needs a non-OATI system, and the method must exceed online packing,
exact constrained-permutation inference and connection-order path dependence.
