# EcoMD registered-market truth-asset audit

The outcome-blind audit is
`papers/proposal/ecomd_reentry_truth_asset_registry_audit_2026-08-26.md`. It is a trigger audit,
not a topic cycle, and authorizes no result access or execution.

## Durable result

- The live AEA RCT CSV retrieved on 2026-08-26 contained 12,635 public registrations and 8,887
  records marked `in_development` or `on_going`. A bounded market-language screen produced 76
  broad hits; the five closest interacting-market protocols still lacked a joint raw event schema,
  dated release, untouched confirmation source and independent same-estimand replication.
- OSF registration `xagjc` is a real pre-data randomized asset-market protocol that plans to record
  beliefs, bids, asks, prices and quantities. It does not freeze an order-lifecycle schema or raw
  release, has at least five small sessions, and is not a field-rule counterfactual.
- OSF registration `3by86` includes hashed z-Tree continuous-double-auction programs, but its
  collection window was in 2025 and the registered object contains no raw data or independent
  replication contract.
- OSF registration `8g3jw` is an immutable prediction-market replication protocol, not an assigned
  same-state market-rule response.
- A registration licence is not automatically a future raw-data licence. Mentioning bids and asks
  is not equivalent to immutable order IDs, replacement ancestry, partial fills, residual quantity,
  actor roles, timing and replay-complete pre-state.

The append-only entry `registered_market_experiment_truth_asset_screen_20260826` is
`not_trigger`, with `candidate_harvest_authorized: false`. The provisional 15% brake was not used;
hard evidence-contract failures decide the audit.

## Re-entry condition

Re-audit only after a pre-data immutable protocol commits to a file-level event schema, assignment
key, replay-complete pre-state, dated licensed raw release, whole-source confirmation partition,
and an independently governed replication with the same action, clock, state, observation and
outcome grammar.

No outcome access, data acquisition, participant experiment, simulation, implementation, purchase,
outreach, EcoMD change, sandbox, CPU experiment or GPU use is authorized.
