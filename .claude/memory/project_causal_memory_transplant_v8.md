# Causal memory transplantation in agentic economies v8

Started `observable-state-mechanism-search-v8` from clean integrated
`main@132640630d1e71257642cba967e5ecc3a15c0f3f` on 2026-08-13. Frozen plan:
`papers/proposal/plan_causal_memory_transplant_agentic_economies_nmi_ncs_v8.md`.

V8 does not reopen the V6/V7 latent-adaptation claim. It changes the information source: in a stateless
computational agent, explicit episode memory can be read, erased, randomized or transplanted after a real process
and mechanism reset while weights/instructions remain fixed.

The sole initial `SCOUT` candidate is a signed memory-carried response. A randomized source regime creates a memory
capsule; intact, semantic-scramble, erased and unrelated capsules are randomized into independently restarted
recipient economies. The unit is an economy, and the primary contrast is donor-regime response under intact memory
minus the corresponding semantic-scramble response.

The claim is restricted to audited computational agents. It is not human memory or real-market physics. The
dynamic-pricing/agent-learning phase-boundary idea was rejected before candidacy because competitive online
learners under resource-centric pricing, monotone load-balancing games and safe nonstationary pricing already
cover it directly.

Current authorization is primary literature, protocol design and hand-derived transparent-agent fixtures on at
most 30 local Mac CPU core-hours. No model inference, generated outcome, API call, human/market data, remote host,
V100, RTX2060, GPU job or H20 assumption is authorized until N0/I0/S0 survive and a separate preregistration is
committed.
