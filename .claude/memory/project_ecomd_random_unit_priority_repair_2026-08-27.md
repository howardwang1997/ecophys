# Random-unit priority repair (2026-08-27)

## Current scientific object

The historical random-within-tie thesis is superseded scientifically, though retained as
provenance. The current question is whether uniform random allocation over resting units at an
equal price reduces humans' costly investment in queue speed, and whether that mechanism transfers
to a full induced-value CDA. The paper must identify the two lab populations, not call them a “real
market,” and must not claim a universal liquidity sign.

The primary causal module is an isolated same-price race: every unit rests before one demand unit,
and participants choose costly message latency. FIFO makes speed affect rank; random-unit allocation
makes each unit's probability `1/N` independent of speed. First-round normalized speed investment
before own fill feedback is the sole primary outcome. Full-CDA depth, spread, efficiency,
cancellations, surplus and concentration are secondary transfer outcomes.

The interpretation uses an observable nested ladder: M0 aggregate-lumpable, M1 identity/resource
myopic, M2 feedback-adaptive, M3 rule-aware forward-looking. An aggregate effect rejects only M0;
it does not establish strategy. M3 requires a pre-feedback treatment response. The historical C2
depth lemma is only a threshold-family comparative static.

## Treatment and implementation

Treatment is `fifo` versus `random_unit_within_price`. Random allocation samples each executed unit
uniformly without replacement from all remaining resting units at the execution price. This is
quantity-weighted at the order level and invariant to contiguous child-order splitting. FIFO
partial fills retain their rank. Depth is measured in units.

The A-2 reference kernel now records semantic random draws and latency choices; maintains order
lifecycle/ownership; reserves and settles cash/inventory; enforces induced buy/sell unit capacity;
tracks induced surplus and information releases; loads the initial book; and commits prestate,
queue order, economic state, counters and RNG state in the full hash. The anonymous hash is compared
only at common request boundaries because random-unit execution can emit more records than FIFO.
Replay compares pre/post identity and anonymous hashes plus payloads.

Regression tests cover the original partial-FIFO witness, random-unit weighting and splitting
invariance, resource/value constraints, queue-order hashing, cross-arm request-boundary invariance,
latency choice, the isolated speed-rent fixture, exact replay and tamper detection. Robot outputs
remain engineering-only and are not route evidence.

## Precision and status

The old spread-based 16-sessions-per-arm calculation and terminal USD 20,000/site C4 pass are
withdrawn. At 16 sessions/arm, 80% two-sided power requires approximately `d=1.024`. The provisional
SESOI is 0.10 of the latency endowment, but no `n` can be frozen until the payoff scale and a relevant
between-session variance are available. C4 is open. Robot variance cannot calibrate human power;
any human variance pilot requires ethics and explicit authorization.

## Publication assessment

With a valid two-site study, the best ladder is Management Science only for a large replicated
effect plus CDA/welfare/practice consequences, then Journal of Financial Markets, then Experimental
Economics. If only the clean speed mechanism survives, start at Experimental Economics; JEBO is a
good fallback. A decisive equivalence/null can publish if the TOST interval and replication are
strong. Quantitative Finance is a lower-risk technical fallback. NeurIPS is a poor fit without a
general multi-system simulator-validation method; PRL/Nature Physics are below 0.5%.

Reviewer estimates from the repaired state: 75--85% that exact novelty survives final audit;
25--45% that a meaningful two-site design fits the current ceiling once variance is known; 65--85%
specialist-journal publication conditional on completing a valid study; 20--35% eventual reputable
publication from today's state; 3--8% Management Science/top-field from today's state. These are
reviewer judgments, not route-graph probabilities or calibration entries.
