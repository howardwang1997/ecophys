## Lasting scientific facts

- The treatment must be intended child size before matching, including failed and zero-fill attempts.
  Realized fill size is a post-treatment mediator/selection variable.
- Parent self-selection limits transport but does not invalidate a within-randomized-parent excursion
  effect. Adaptive catch-up is also not intrinsically fatal when the complete history and known
  conditional assignment probability are logged.
- Shared market prices make the market one experimental unit. Concurrent assignments and temporal
  carryover require a frozen exposure mapping and cluster/carryover-aware inference; slices cannot be
  treated as independent units.
- A minimal observational twin proves non-identification when assignment is hidden: one model lets
  latent liquidity drive both fill and response with zero assignment effect; another lets assignment
  drive both with effect one. Both generate the same fill/response distribution. A parent
  `randomize=true` flag does not distinguish them.

## Source and collision audit

- Official Hyperliquid documentation supplies the parent randomize flag and a ±20% child-size support
  statement but not the exact distribution, rounding law, RNG seed/commitment or per-child draw.
- Official node output can include parent TWAP statuses, every order status, fills, raw book diffs and
  block metadata. Order statuses expose an order size but the documented schema lacks the parent TWAP
  ID; filled children can be joined through fill-level `twapId`, while unfilled children cannot be
  linked unambiguously. A node is therefore a plausible future capture path, not a qualified asset.
- Hydromancer/Reservoir and the Barone--Lillo pipeline are fill-centered. The latter downloads parent
  statuses through an unreleased Allium query and builds “slices” from executed market-order fills;
  it does not use the randomize flag as assignment.
- Barone--Lillo directly occupies generic Hyperliquid TWAP impact, sunshine, execution-schedule and
  liquidity claims. Leclère et al. occupy exact shared-noise point-process counterfactual impact;
  Zhou et al. occupy simulator-only splitting-plus-replenishment square-root attribution. MRT/WCLS
  and switchback work are direct estimator/carryover parents.
- The residual ICLR thesis exists only if the field assignment tape exists: observational fit versus
  exchange-randomized interventional response and model-specific abstention regions. “EcoMD reproduces
  TWAP impact” is not novel enough.
