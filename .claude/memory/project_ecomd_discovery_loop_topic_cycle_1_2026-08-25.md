## Reusable rules

- Test the complete exchange state before attributing physical meaning to a projected-state
  cascade. Deterministic feasibility projection, threshold reset, batch deletion, and
  cumulative-depth clipping are not new collective laws merely because owner or control
  state is hidden from L2.
- A market grammar must predict more than its algebraic invariant. Close-only implies only
  nonincreasing open interest; it does not imply an annihilation exponent or phase.
- Same order-type names across venues do not establish same-estimand independent
  implementations. Priority, resize, trigger, reset, and settlement semantics are part of
  the scientific object.
- A prospective proposal is not a truth asset when it is unfinalized, bundled, systemwide,
  endogenously activated, or missing complete pre-state and a sealed confirmation unit.

The next search should start from either an exact market-specific theorem object that
survives complete-state and unit-refinement twins, or a qualified unopened truth asset with
separable assignment, complete pre-state, lawful rights and an independent same-estimand
implementation. Do not continue enumerating exchange flags from this family.
