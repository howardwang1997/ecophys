# EcoMD nonlinear-impact memory-order trigger audit — 2026-09-05

- Lee, arXiv:2609.02447v1 (2026-09-02), is a genuine post-closure theorem source. For every nonzero
  integrable Volterra memory, universal round-trip safety forces the rate-inside nonlinearity to be
  affine; for a convolution kernel it is linear. Signed power impact is therefore manipulable for
  every exponent other than one, including with weakly singular memory and a fixed speed cap.
- For the scalar state-outside model `D=G*v`, `cost=int v h(D)`, safety for every input and every
  continuous monotone `h` is equivalent to complete positivity of `G`. A nonzero safe kernel has a
  complement `L=beta delta_0+ell dt`, with `beta>=0` and `ell>=0` nonincreasing, satisfying
  `L*G=1`; every failure has a finite piecewise-constant negative-cost witness.
- EcoMD's current price head is neither `G*f(v)` nor `h(G*v)`: its input is aggregate latent-agent
  displacement, its later Hawkes-like state depends nonlinearly on return magnitude, and no trader
  execution/cash-cost semantics or admissible round-trip control exists. The theorem cannot be
  applied without changing the model's scientific meaning.
- The obvious safe learner -- monotone neural `ell`, triangular solve for `G`, monotone neural
  readout -- is a direct composition. Clément--Nohel gives the complement characterization;
  UMNN gives expressive monotone functions; standard Volterra stability yields density for bounded
  kernels with `beta` bounded away from zero; Neural Laplace and Volterra GP methods learn long
  memory; passive RKHS, PoDiNN and PHNN methods learn constrained dissipative dynamics.
- At finite resolution, safety reduces to complete accretivity of the inverse state map:
  off-diagonals nonpositive and both row and column sums nonnegative. Feng--Li already characterize
  complete-positive uniform and nonuniform pseudo-convolution kernels, and R-CMM schemes preserve
  variable-step monotonicity. Parameterizing an M-matrix-like inverse and differentiating through
  it is useful engineering, not an irreducible ICLR method.
- RL manipulation search is directly occupied by arXiv:2607.06121, while learning-agent
  square-root-impact manipulation cycles are directly claimed by arXiv:2607.05141. Abi Jaber et
  al. already solve nonlinear state-outside propagator optimization with power-law memory.
- A follow-up closes the universal convex-readout matrix branch: rank-one quadratic potentials
  force `G=g I`, and the scalar converse then forces complete positivity. The only narrow theorem
  boundary worth future review is a fixed market-native nonlinear readout with genuinely
  noncommuting memory. The raw singular-memory alternative is also closed: the fractional
  zero-feedthrough complement has an unbounded same-`L2` inverse, and exact product integration
  satisfies `kappa_2(A_N) >= N^gamma/sqrt(2 gamma+1)`. A cone-specific conditional/minimax result
  would have to exceed scalar complements, fractional inverse theory, matrix positive type, MIMO
  Zames--Falb/IQC, recent factor cross-impact, simultaneous diagonalization, M-matrices,
  sequential Tikhonov, Hilbert-scale Abel regularization, shape-constrained stable splines,
  ICNN/UMNN and port-Hamiltonian networks. This is not a candidate.
