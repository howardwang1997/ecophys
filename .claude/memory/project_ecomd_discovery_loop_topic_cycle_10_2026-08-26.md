coupling, so the proposed result is imposed by the added interaction graph rather than market
heterogeneity alone. Ordinary L2 also lacks persistent provider state.

process with observable order ages can generate a post-relaxation bilinear echo and a complete-state

pass T0, and authorizes no simulation.
