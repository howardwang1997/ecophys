# EcoMD Discovery Loop topic cycle 3 — capability-first screen

On 2026-08-25 the third bounded topic cycle began from public, versionable, replayable market
capabilities rather than a physics analogy. The formal result is
`papers/proposal/ecomd_discovery_loop_topic_cycle_3_capability_first_result_2026-08-25.md`.

Pinned read-only implementations were Manifest, Mangrove Core, OpenBook v2, and Phoenix. The
cycle closed eight formulations:

- shared-capital global-order exclusion;
- bonded executable-liquidity promises;
- deferred-settlement event-heap backpressure;
- lazy-expiry matching maintenance debt;
- regenerative reverse-order lattice dynamics;
- tickless priority inversion;
- global-account lock contention; and
- programmable-offer executable-liquidity oracles.

The strongest near miss was shared-capital global orders at hostile T0 5--17%, point 10%.
It exposes a real nonlocal conservation mechanism: one deposited balance can support offers
in several markets, and a fill can make sibling displayed liquidity unexecutable. It still
fails the Nature-grade gate. With offers and arrivals frozen, the process is online packing,
sequential knapsack, or a loss network. With unrestricted maker contracts, it can encode
arbitrary state-dependent dynamics. Manifest and Mangrove also differ in funding, failure,
cleanup, execution, scheduling, and bounty semantics, while duplicated-then-cancelled
liquidity is already direct empirical prior art.

Durable gates:

1. **Resource--program dichotomy:** first freeze policy and attempt an exact capacity-allocation
   reduction; if arbitrary code is admitted, require a native restricted-program invariant.
2. **Execution denominator:** a confirmed chain ledger is complete for successful state
   transitions, not for all dropped, private, replaced, or failed submissions. It cannot
   identify landing or failure probability without that denominator.
3. **Debt-semantics equivalence:** deferred settlement, atomic settlement, synchronous
   removal, prepaid cleanup, and bounty-bearing failure are different estimands.
4. **Truth capability is not novelty:** exact protocol implementations are excellent
   conformance and counterexample fixtures, but do not make packing, queueing, grid,
   scheduling, or program analysis into new market physics.

No topic card, D-1 candidate, sandbox, simulation, chain outcome query, data action,
outreach, EcoMD edit, or GPU is authorized. Reopen only with a protocol-forced theorem that
provably escapes the exact parent reductions, two independent implementations with the same
native semantics, complete opportunity exposure, and a frozen prospective confirmation.
