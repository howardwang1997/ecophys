# EcoMD tail-cardinality pooling trigger audit — 2026-09-05

The proposed small-to-large repair is **`not_trigger`**. Exp-123/125/126 were generated by the
stochastic-pair model, not MACE-lite. Raw excess-demand Hill is nearly flat over
`N=100..30000`, while only the downstream finite-sample return Hill rises; the repository already
requires zero-noise/fixed-SNR decomposition before interpreting that change. A MACE readout or mean
pool therefore is not the evidenced cause.

An exact witness closes marginal-tail-index pooling. For identical regularly varying node marginals
with alpha 3/2, independent nodes require sum normalization of order `N^(2/3)`, while perfectly
common shocks require order `N`. A scalar exponent learned only from marginal alpha cannot preserve
both laws. Dependent stable-limit theory assigns the missing information to the extremal cluster or
tail process. Weighted agent splitting independently changes latent `N` while preserving an
economic aggregate, so EcoMD particle count remains non-native.

Graph size-generalization theory, trainable Lp-like pooling, PNA degree scalers, mesoscopic-SDE
learning, neural RG, and the 2026 Mori--Zwanzig memory GNN for intermittent heavy-tailed particle
dynamics occupy all easy components. The only possible re-entry object is a constructed
spatial-temporal tail-process operator with a new dependent-path transfer theorem, projective
unit-splitting invariance, and frozen analytical/gold truth on two independent dynamic systems.
No such object currently exists; candidate harvesting, implementation, simulation, SSH, and GPU use
remain closed.
