# EcoMD Discovery Loop topic cycle 15

Cycle 15 stayed inside simulated markets, market microstructure, and financial physics. Twelve raw
programs became six quick screens, three six-work collision screens, zero F3 audits, and zero cards.
The terminal report is
`papers/proposal/ecomd_discovery_loop_topic_cycle_15_market_maker_obligation_result_2026-08-26.md`.

## Terminal result

- `mrx_cross_role_quote_obligation_pooling` is failed-closed. Combining fulfilled quote seconds
  across PMM and Preferred-MM roles strictly enlarges the compliance feasible set, but it does not
  assign a dynamic quote response. That response needs private member costs, inventory, adverse-
  selection state and policy. Public options data lack member/badge/role attribution, the proposed
  post-period starts after the audit, and Phlx is the same Nasdaq rule family.
- `jpx_daily_monthly_sponsor_temporal_pooling` is failed-closed. Daily/monthly assessment is jointly
  selectable with ETF, target interval, weights, payment, ranking, rewarded-maker count and quote
  obligations. Asset managers assign the package endogenously; public aggregate ETF statistics do
  not supply maker costs, inventory or randomized same-contract assignment.
- `polymarket_relative_liquidity_reward_contest` is failed-closed. Normalized reward shares are
  invariant to common score scaling, while ownership permutation changes rewards without changing
  an anonymous order book. The mechanism is a proportional contest conditional on maker costs;
  dYdX supplies the formula lineage and a direct review.
- MOEX sufficient-volume crossing only releases an obligation. It neither forces withdrawal nor
  supplies an exogenous event time.

No program reached F3, so no prospective full-T0 forecast was created. The provisional 15% brake
did not close any route and receives no new calibration evidence.

## Durable process changes

- Separate a compliance feasible-set change from an assigned participant action.
- Do not treat a daily/monthly label as a clock intervention when the rest of the contract is
  jointly selectable.
- Apply common-scale and quote-owner-permutation twins to normalized liquidity rewards.
- Treat a quota hit as an endogenous stopping time and permission change unless the protocol
  directly executes an action.

These are applications of existing resource-pooling, state-completion, assignment and invariance
gates; no new machine protocol field was needed. No simulation, outcome access, dataset action or
purchase, sandbox, outreach, EcoMD edit, implementation, or compute is authorized.
