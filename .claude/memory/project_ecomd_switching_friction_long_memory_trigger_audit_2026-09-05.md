# EcoMD switching-friction long-memory trigger audit

- Rodriguez Dominguez (arXiv:2609.02525v1, 2026-09-02) derives a genuine half-index
  restriction: under aligned `q^2 lambda^2 v` weights, the representation-spell duration tail and
  signed-flow covariance exponent both equal `theta/2`; a truncated-Pareto benchmark gives a
  finite-population cutoff near the squared maximum residence scale.
- The paper's experiments are structural simulations, not market evidence. Its own direct-test
  contract requires dated representation states, account identifiers, signed executions,
  reconstructed parent orders, aligned weights, common-shock controls, and held-out evaluation.
- Exact nonidentification witness: take binary constant demand within each admissible representation
  spell, set transitory flow to zero, and call each spell a parent order with the same duration,
  direction, quantity, intensity, and Poisson tape. The complete marked execution path, duration
  exponent, flow exponent, and cutoff are identical. No anonymous or merely wallet-labeled tape can
  decide which semantic latent generated it.
- Public account count is not the theorem's iid portfolio count: splitting one owner into cloned
  wallets changes observed `N` but not the aggregate path or maximum residence scale.
- dYdX fixed funding carry is not a mechanism-specific exclusion. Carry can change representation
  residence, desired position duration, metaorder sizes, and execution horizons; the same
  carry-conditional duration law gives identical flow under both mechanisms. The old boundary
  dipole tests a carry response, not replacement of a model or factor set.
- The frozen dYdX route also remains support-failed: only one of 21 development markets met the
  activity rule versus a stop line of 15. Accounts and hourly boundaries cannot be promoted to
  independent assignments for one market-level governance transition.
- Implementing the new mechanism in EcoMD would reproduce a programmed renewal model; fitting a
  neural semi-Markov state cannot identify latent provenance; public aggregate exponent agreement
  is only compatibility evidence. The positive theorem itself is now directly occupied.
- Decision: `not_trigger`, zero blockers removed, no candidate harvesting, outcome access,
  implementation, simulation, SSH, or GPU. Re-entry needs an externally versioned representation
  panel with parent links and same-estimand replication, or a valid assigned exclusion that changes
  representation replacement cost but not execution/metaorder horizons, plus a residual beyond the
  2026 half-index and cutoff results.
