# EcoMD Hyperliquid TWAP assignment reconstruction (2026-09-04)

## Canonical decision

Joining `node_twap_statuses`, `node_order_statuses`, fills and `replica_cmds` does not currently
recover a design-identified native-TWAP assignment tape. A unique-matching test is a conditional
audit capability only: it requires an authoritative complete scheduler, exhaustive order-source
taxonomy and a complete pre-match attempt stream. Those premises are not established by the public
schemas. The audit removes zero blockers, authorizes no topic/card or candidate harvesting and leaves
all data access, node deployment, implementation, EcoMD integration, SSH and GPU work closed. The
separate Paper D machine decision is unchanged.

## Lasting formal result

- Freeze intended attempt slots and candidate order rows using pre-outcome fields. A linkage-
  dependent estimand is identified only if it is invariant over every feasible linkage; the linkage
  itself is identified only when the feasible set is a singleton.
- In ordinary bipartite matching, a feasible perfect matching is unique iff there is no alternating
  cycle. This is an audit criterion, not a novel ML theorem, and is valid only relative to a complete
  candidate/source set.
- Two same-user, same-asset, same-side parents with overlapping due windows and two compatible
  zero-fill rows induce a `K2,2` graph. Swapping the parent links preserves all public rows, fills and
  aggregate executed progress but changes the parent history, adaptive base and propensity paired
  with each intended size. Parent-conditioned excursion effects and model losses are not identified.
- An apparently collision-free row is not certified when non-TWAP internal sources are not
  exhaustively tagged and the exact scheduler is not authoritative.

## Source and novelty audit

- Pinned Bitquery and Sorella schemas corroborate that parent state and child order status live in
  separate shapes and that order rows have no declared parent-TWAP field. Both are third-party and
  had no detected repository license, so official L1 documentation remains controlling.
- SQD replica commands expose action metadata/payloads but do not document a bijection from internal
  scheduled children to order OIDs or prove that signed-action subtraction exhausts other internal
  sources.
- The pinned `can1357/hl` source reports a per-user schedule, delayed first fire, thirty-second
  advancement, progress and retries. Its own README calls it unofficial reverse engineering; it is
  incomplete/noncompiling, unlicensed at the pinned revision and contains no recovered child-size
  RNG law/draw, rounding or parent-child OID link. It is hypothesis-generating evidence only.
- Shan et al. (2021) and Guha--Reiter (2024) already propagate probabilistic link uncertainty into
  causal inference under model/ignorability assumptions. Zhu et al. (UAI 2022) covers causal
  treatment measurement error with an IV structure. A posterior over links does not reconstruct a
  randomization design; generic linkage-error methodology is not an unoccupied ICLR claim.
- Exact propensities are not necessary for every model-based conditional analysis under assumed
  sequential ignorability, but the proposed field-truth benchmark needs observed intended treatment,
  complete history and an auditable assignment mechanism. Unique linkage alone would not clear the
  independent RNG/design blocker.
