## Durable findings

- Appending finite-dimensional Hawkes or recurrent memory to the particle state restores a Markov
  state. Slow memory degrades the augmented spectral gap; that alone is not a new non-Markovian RBM
  object. Existing variance-reduced RB Langevin work already estimates force variance and corrects
  artificial heating/FDT error, while random reshuffling, stochastic-gradient and covariance-
  controlled thermostats, momentum, multi-species, Levy and neural-attention variants occupy the
  obvious extensions. Re-entry requires a new correction and bound uniform in a declared slow-
  memory limit.
- Finite-size mesoscopic SDE learning is directly demonstrated in stochastic pairwise flocking,
  and a 2026 learned renormalization flow already transfers small-lattice training to large-system
  finite-size scaling and critical fluctuations. EcoMD's latent particle count is analyst-selected:
  splitting one latent agent into weighted replicas can change `N` while preserving aggregate
  paths. No population-size physics claim is legal without an economic unit and a refinement-
  invariant response.
- A Hill statistic is smooth when the top-k membership/order is locally fixed, so autodiff through
  it is elementary. The hard problem is rare-event occurrence, dependence, threshold selection and
  rank/support changes. Pareto GAN, tail-weighted calibration, CVaR-GPA and differentiable kernel-
  score simulator calibration occupy the generic method space. The project Hill lineage is also
  burn-in contaminated.
- The Halim CC-BY-4.0 archive has useful raw order, transaction and lifecycle schemas plus programs
  for sixteen sessions, but no documented market-cell assignment key, untouched confirmation or
  independent exact midpoint-pool replication. Huber has 166 preregistered markets and within-
  session assignment, but its behavioral treatments are not exchange actions, order semantics
  differ from the original, the outcome source was unlicensed in the prior audit, and both effects
  are already public.
- For simulator summary means `mu(theta)`, a separating vector can certify only that a target lies
  outside the closed convex hull of the attainable set. It cannot decide points inside that convex
  hull but outside the nonconvex simulator manifold; a local Jacobian is not a global certificate,
  and numerical maximization gives the wrong inequality direction for certification. Robust NPE
  and current preconditioned robust NPE already treat incompatible summaries and simulator
  misspecification. Preserve the support-function inequality as a diagnostic, not a paper claim.

## Re-entry condition

Re-audit only for one written object: a slow-memory-uniform RBM theorem/correction; a market-native
refinement-invariant population scale; a calibrated dependent-path tail gradient through support
changes; an assigned replay-complete licensed intervention with sealed independent confirmation;
or a computable global nonconvex simulator-reachability certificate with finite-simulation coverage
and a matching hardness boundary. A trigger would permit only a bounded child screen, not compute.
