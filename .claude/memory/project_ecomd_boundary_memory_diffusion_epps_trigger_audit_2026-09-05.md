# EcoMD boundary-memory, diffusion, Epps and smoothing trigger audit

- **Retained hidden excess:** Das (arXiv:2608.08625) gives a useful clipped recursion, tail-amplitude
  law and wide-band persistence ceiling. With `nu=3`, the ceiling is `0.1681`; reported pooled
  persistence is `0.7885`, `0.4478`, `0.2674`, `0.1452` at 2/5/10/20%, and the 20% lower side is
  `0.2045`. The narrow-band violations delimit the asymptotic map; the wide lower-side violation
  and one-lambda band/direction mismatch prevent a structural calibration claim.
- Exact nonidentification: for any observed clipped process `R_t`, the no-retention construction
  `lambda'=0, X'_t=epsilon'_t=R_t` reproduces it pathwise with a serially dependent driver. Passive
  returns cannot distinguish retained iid overshoot from persistent forcing or adaptation.
- NSE band variation is endogenous. Official rules make downward review daily, upward review
  bi-monthly and conditional on surveillance criteria; ASM uses price/volume variation, volatility,
  client concentration, market cap, delivery, unique PANs and PE. These variables also predict the
  response, so band width is not an instrument. Dynamic Tobit and varying-saturation system
  identification occupy the generic estimator route.
- **LMF diffusion:** Sato--Fujiwara--Kanazawa (arXiv:2608.00988) already own the theorem that
  `delta <= 1/2` is necessary and sufficient for diffusion for all long-memory exponents in their
  model class. Their real nonzero-permanent versus zero-permanent propagator fork needs same-unit
  parent-metaorder, child-schedule, peak/permanent-impact and decay truth.
- `tse_tick` is useful MIT parsing infrastructure, pinned at
  `01d74d8e283a3e4d2774f277b1ff22c6234c5359`, but supplies no data and requires an institutional
  Nikkei NEEDS subscription. Its anonymous trade/quote schema does not add participant,
  beneficial-owner or authoritative parent links, so the old metaorder gate remains.
- **Coupled Epps:** arXiv:2606.14182 was already cited in cycle 2 and the exact mechanism question
  was pruned in cycle 10. Its clock-times-response product is leading-order under exogenous clocks;
  a single Epps curve has nonunique factorization, and common-information/Hawkes/lead-lag kernels
  can reproduce the price law without a pair-trader reaction front.
- **Stochastic tracking:** Nutz--Voss (arXiv:2608.29468) already own sharp roughness-dependent value
  rates and the jump/block-execution smoothing application. Value convergence does not control
  policy identity, active sets, event times, constraints or expected-gradient error. Adaptive
  Barrier Smoothing and mixed-order differentiable-simulator gradients occupy the obvious repair.
- Decisions: four `not_trigger`, zero blockers removed, no candidate harvest, implementation,
  outcome access, simulation, SSH or GPU. No graph node was added because all four formulations
  map to existing failed-closed routes. Re-entry requires an actual assigned intervention,
  authoritative parent/action truth, a joint hard-event semantic theorem, or an independent
  same-estimand truth system—not another EcoMD implementation of a programmed mechanism.
