# Algorithmic fee-market dynamics v6

Started `algorithmic-fee-market-dynamics-v6` from integrated
`main@efe14ad44a0ce208d082672e2c2f7d55de119606` on 2026-08-13. Frozen plan:
`papers/proposal/plan_algorithmic_fee_market_dynamics_nmi_ncs_v6.md`.

The lead scientific object is the coupled execution-gas/blob-gas resource market: exact protocol controllers map
resource use and fork-specific parameters to future base fees, while user, builder and rollup demand is adaptive
and partly latent. V6 is not a cryptocurrency-price paper and EcoMD is not its discovery system.

The NCS candidate is prospective cross-regime prediction: estimate a response operator before a declared capacity
change, combine it with the exact new controller without refitting behavior, and predict the signed joint
post-change response with independent replication. A one-upgrade event study, blob-only occupancy plot or
post-change refit is insufficient. The NMI route additionally requires a theorem/method outside established
closed-loop system identification, IV and structural demand estimation, with non-blockchain validation.

Initial authorization is specifications, test vectors, primary literature and catalog/schema/licence metadata
only: <=30 Mac CPU core-hours, no chain outcome values, paid data, remote host, queue or GPU. Current compute remains
two V100 32 GB plus one RTX2060 and may expand to non-H20 pools; H20 is excluded. Before any outcome, V6 must pass
exact-controller, novelty, free-data, causal-identification and metadata-scale generated-power gates.
