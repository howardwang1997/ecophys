# EcoMD Discovery Loop topic cycle 8 — cross-engine discrepancy

The formal result is
`papers/proposal/ecomd_discovery_loop_topic_cycle_8_cross_engine_discrepancy_result_2026-08-26.md`.

Cycle 8 asked whether disagreement between independent stateful market simulators could reveal a
missing physical mechanism. It produced a reusable trilemma. If two engines implement one complete
kernel, action compiler, policy filtration, observation map, clock, and randomness coupling, their
observable path laws agree and any difference is a conformance defect. With frozen policies, an
event-driven versus batched difference is standard jump-process operator-splitting error. With
adaptive policies, the native ABIDES, PAMS, and Bourse runners give agents different histories and
reaction opportunities, so they implement different market mechanisms rather than independent
replications of one estimand.

Three nonduplicate descendants failed closed: the hard-boundary batch shadow generator, adaptive
scheduler information-filtration response, and a cross-simulator disagreement intervention
certificate. Exact-kernel docking and action-packet/shared-seed discrepancy were not added again
because verified matching conformance, partial-order semantics, and common-randomness coupling
already cover them. Hostile-T0 intervals were 1--17%; the largest conservative lower bound was 3%,
below the 15% activation floor.

Status is passed-and-closed with zero cards. A fixed exogenous tape may validate matching semantics
but suppresses adaptive response. Simulator agreement is not external validation, and disagreement
is not a calibrated uncertainty certificate without prospective external truth. Reopen only with
two native engines exposing one bit-complete state, physical clock, action and information contract,
isolated semantic randomness, and a residual outside docking, splitting, partial-order semantics,
market-design comparative statics, and causal/model discrepancy. No sandbox, simulation, data
action, outreach, EcoMD edit, or compute is authorized.
