# 2026-04-25 — v2 ablation 33-run dead end → v2.1 breakthrough (6/11)

## TL;DR

跨夜实验：v2.0 在 33 个超参组合下全部锁死 4/11，逐项排除后定位**两个隐藏 bug**：
1. Ilinski gauge invariance 误用于 agent position（不是 log-price）
2. T 矩阵 identity 初始化抑制 75% 的 inter-type pair force

修复后 → **v2.1 在 Mac 复现 6/11**，与 v0.6 持平，保留架构 novelty。
H20 配置已就绪等待 N=10K 大跑。

## Session 21 — v2 实现 + 33-config ablation + v2.1 breakthrough

### 22:00–01:00 实施 v2.0

按 plan 设计的 5 对称推导架构。三个 module：
- `KyleGlobalPotential` — `λ·||(1/N)·Σ π_θ(s_i, τ_i)||²`
- `TypedRelationalPotential` — `T_θ[τ_i, τ_j]·φ_θ(Δs_ij, τ_i, τ_j)` over k random edges
- `TypeEmbedding` — 持久 K=4 类标签 + learned embedding

12 unit tests 覆盖 5 项严格不变性（permutation-within-type, gauge on s[0], etc.）。
Mac smoke：4/11，loss 收敛但比 v0.8 (7/11) 差太多。

### 01:00–02:00 第一轮 ablation：mac_quick (16 runs)

Sweep `kyle_λ × phi_gain × w_shape`：
- λ ∈ {0.05, 0.5, 2.0}
- gain ∈ {0.5, 1.5, 3.0}
- w_shape ∈ {0.0, 0.5}

**全部 4/11**，loss/shape/lb_p 全部接近相同（0.71/1.27/0.25）。

### 02:00–02:30 诊断 grid (8 runs，5 完成后被中断)

测 Kyle on/off × gauge ∈ {-1, 0} × k ∈ {50, 199}。

5 个完成结果**完全相同 4/11**。force probe 揭示：
- v0.8 PairwisePotential 训前 `|F|=0.76`
- v2 默认 `|F|=0.054`（**14× 太弱**）
- 提到 phi=3.0 → `|F|=46`（**60× 爆炸**）
- 中间 phi=1.0 → `|F|=0.88`（理论命中 v0.8 量级）

但 mac_quick 跳过了 phi ∈ [0.8, 1.2]，所以一直没见到 force-magnitude 正确的运行。

### 02:30–03:00 phi_tune grid (12 runs at phi ∈ {0.8, 1.0, 1.2})

**全部 4/11**！

即使 force 量级匹配 v0.8（phi=1.0 时 `|F|=0.88`），passing count 不变。Loss 系统下降 (0.72→0.69→0.65)，说明训练 loss 的 3 个 target 在改善，但**其余 8 项 stylized facts 与 loss 解耦**。

到此 33 个 v2.0 configs 全部 4/11。架构层面有问题，不是 hyperparam。

### 03:00–03:30 Force probe + 结构分析

测 v2 各 architectural variant 的 force magnitude：
- v2 (Kyle off, gauge off, k=199, phi=0.5) `|F|=0.057`，依然小

**关键观察**：v2 的 pair input 只有 `[Δs, τ_i_emb, τ_j_emb]` = 48 dim。v0.8 的是 `[s_i, s_j, |s_i-s_j|]` = 96 dim。**v2 不能学 `f(|s_i|)` 类函数**——而 vol clustering 需要 agent 对自己 state 幅度响应。

**第一个 bug**：Ilinski gauge 不能用于 agent position。我之前推导以为 s[0] 是 log-price，实际是持仓量（absolute meaning，不能 gauge）。

### 03:30–04:00 修 gauge_enforce → 仍 4/11

加 `gauge_enforce: bool` knob，设为 false 后 pair input 变成 `[s_i, s_j, |Δs|, τ_i_emb, τ_j_emb]` = 96+16 dim。Mac smoke：**仍 4/11**，loss 0.698。

但 ACF metrics 还是 flat（acf(r²)=0.006）。说明只是 gauge 不够。

### 04:00–04:30 T 矩阵分析 → 第二个 bug

T 默认初始化 `T = eye(4) + 0.1·randn`。对角≈1，非对角≈0.1。
4 类随机分配，**P(同类) = 25%**。25% edges coupling≈1，75% coupling≈0.1。
**75% 的 edges 在 init 被 ~10× 削弱** → effective force 是 v0.8 的 ~30%。

加 `T_init_mode: ones` knob。重跑 Mac：

```
A: T=ones, Kyle off, phi=0.5, gauge off  →  4/11   |F|=0.85
B: T=ones, Kyle off, phi=1.0, gauge off  →  6/11 ✓ |F|=7.76
   #5 Fano = 4.70   #6 ACF(r²) = +0.109   #10 corr(V,|r|) = +0.265
```

**B 突破！** 三个 vol clustering / volume coherence 全过。

## Session 22 — Hawkes × shape sweep, v2.1 hits 9/11 on Mac

**目标**: 在 v2.1 base recipe 上扫 Hawkes κ × ACF shape loss，找 H20 用的最佳配方。

**Sweep**: `hawkes_kappa ∈ {0.1, 0.3, 1.0, 2.0}` × `w_acf_shape ∈ {0.0, 0.3, 1.0}`，
12 configs × 80 iters × N=200。

### 结果（关键）

| κ   | ws  | n/11 |
|-----|-----|------|
| 0.1 | 0.3 | 7    |
| 0.1 | 1.0 | 7    |
| 1.0 | 0.0 | 7    |
| 2.0 | 0.0 | 7    |
| **2.0** | **0.3** | **9 ★** |
| 2.0 | 1.0 | 9 ★  |

完整表格见 `experiments/017_v2_ablation/results/v21_sweep_summary.md`。

### 三个 take-aways

1. **强 Hawkes (κ=2.0) + shape loss (ws=0.3) 协同**：单独看，强 Hawkes 拉 ACF
   lag-1 到 0.45（match real SPX 0.45），但形状会塌成 flat plateau；shape
   loss 单独看，能维持 peak-decay 几何但 ACF 强度上不去。两者结合，9/11。
2. **κ=0.3 是死区**：太弱不能 self-excite，太强又抑制别的项。
3. **9/11 的 2 个 fail**：`autocorr_returns` (sim +0.33 vs real ±0.05) +
   `conditional_kurtosis`。两个都期望在 N=10K 时缓解（总体平均洗掉短期
   return autocorr，更大 population 让 fat-tail 形状更稳）。
