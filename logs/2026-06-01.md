## Session 2 — "one more solve attempt": tail-clamp probe (exp 112) built + smoked

**Goal:** User chose (AskUserQuestion) "one more solve attempt" — close the one untested
mechanistic lever before committing to the diagnose. Build a soft tail-clamp, smoke it, hand off.

**What was done:**
- Added a soft differentiable saturating clamp to the price-formation map
  (`ecomd/models/price_formation.py`): `r_clamped = scale·tanh(r/scale)`, where
  `tail_clamp_mode="rel"` → `scale = c·running_volatility` (clustering-relative), `"abs"` →
  `scale = c` absolute. `tail_clamp_c<=0` (default) = OFF, bit-exact. Flows in via
  `price_formation_kwargs` (no EcoMDConfig change). `tests/test_tail_clamp.py` (6) pass incl.
  OFF bit-exact + saturation correctly zeroing grad on huge inputs.
- exp 112: 5 cells × 20 seeds = 100 cfg (baseline / rel_c8 / rel_c5 / rel_c3 / abs), SPX, N=10K
  fp32, MMD long-rollout every=4. Launcher `scripts/h20_112_tail_clamp.sh --probe`. Committed
  `93a9a5a98`. Pre-registered gate: SOLVE iff hill∈[2,4] AND acf2 stays in band (breaks the
  tail⊥dynamics coupling); else → commit diagnose.

**Directional smoke (Mac, N=400, 1800 steps, n=1 — wiring+direction only, NOT a result):**

| cell | hill | acf2 |
|---|---|---|
| baseline | 3.06 | 0.312 |
| rel_c5 | 5.61 | 0.156 |
| rel_c3 | 4.86 | 0.273 |
| abs | 5.59 | 0.139 |

**Findings:**
1. **The fat-tail overshoot is N-dependent.** Baseline hill=3.06 at N=400 vs **1.39 at N=10K** —
   the dynamical tail-fattening *scales with system size*. This is itself a physics result worth
   a line in the diagnose ("tails fatten toward infinite-variance as N→large"). It also means the
   N=400 smoke is BELOW the overshoot onset, so it previews mechanism *direction* only; the SOLVE
   gate must be decided at N=10K (H20).
2. **The clamp does exactly what it says, and the Pareto coupling shows up even at N=400:** every
   clamp variant THINS tails (hill 3.06 → 4.9-5.6) AND reduces clustering (acf2 0.312 → 0.14-0.27).
   `abs` kills the most clustering (0.139, −55%), as predicted. `rel_c3` retains the most acf2
   (0.273, −12%) among the tail-thinners → most promising cell for the N=10K test (a gentler
   rel_c4 may be the sweet spot). (n=1 noise → c5-vs-c3 ordering unreliable; agg negative because
   N=400 is too short for that estimator — ignore the agg column here.)
3. **Net prediction for H20:** the clamp WILL pull hill up from the 1.39 overshoot toward [2,4]
   (good), at an acf2 cost (the coupling). Whether any rel cell lands BOTH in-band simultaneously
   at N=10K is the open question. My prior: it tightens the frontier but does not break it →
   strengthens the diagnose. If a rel cell holds both → genuine solve → 5-asset confirm.
