## Technical implementation

### V4 mechanisms (ecomd/physics/integrator.py)

**1. Lévy/α-stable noise** (targets hill_tail)
- Chambers-Mallows-Stuck algorithm for α∈[1,2]
- Differentiable, GPU-compatible
- Config: `levy_alpha` (tail index), `levy_scale` (noise amplitude)
- Experiment 077: α∈{1.5, 1.7, 1.9} × 30 seeds

**2. Asymmetric drag γ(Δp)** (targets leverage effect)
- γ_eff = γ · (1 + α·sign(Δp))
- Down moves → higher drag → liquidity evaporation → negative correlation
- Config: `asym_drag_alpha` ∈ {0.3, 0.5, 0.7}
- Experiment 078: 3 cells × 30 seeds

**3. Memory kernel** (targets Zumbach effect)
- EMA(|Δs|) modulates noise scale: σ_eff = σ · (1 + scale · mem)
- Config: `mem_kernel_lambda` (decay), `mem_kernel_scale` (strength)
- Experiment 079: λ∈{0.7,0.9}, scale∈{1,2,3} → 6 cells × 15 seeds = 90 configs

All mechanisms:
- Backward compatible (default params = v3 behavior)
- `reset_state()` method clears internal state between rollouts
- Unit tested (8/8 tests pass)

### Statistical baselines (ecomd/baselines/)

**GBM** (gbm.py)
- Geometric Brownian motion: dS = μS dt + σS dW
- Fit μ, σ from log-returns

**GARCH(1,1)** (garch.py)
- Bollerslev model: σ²_t = ω + α·ε²_{t-1} + β·σ²_{t-1}
- Captures volatility clustering

**AR(1) + SV** (ar1_sv.py)
- Returns: r_t = φ·r_{t-1} + ε_t
- Volatility: log(σ²_t) = μ + ρ·log(σ²_{t-1}) + η_t
- Two-stage MLE fit

**Lux-Marchesi** (lux_marchesi.py)
- Agent-based model (already existed)

Unified runner: `ecomd/baselines/runner.py` outputs `inference_merged.json` format for direct comparison.

### Continuous metrics (scripts/score_continuous.py)

For each stylized fact:
- **KS test**: D-statistic + p-value
- **Wasserstein distance**: L1 distance between CDFs
- **z-score**: (model - target) / target_std

Output: `continuous_score.md` with per-cell ranking by mean |z|.

Already generated for 069 (gamma damping) and 074 (clean physics ablation).
