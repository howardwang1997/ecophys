### S8 — Jarzynski 估计器 power analysis(`scripts/s8_jarzynski_power.py`,已跑)

问题:在现实事件预算(FOMC×3y≈24、财报≈240)下,ΔF̂ = −(1/β)ln⟨e^(−βW)⟩ 能否达到
B2 自己的 15% 判据?合成功分布、真值已知(高斯解析 / 截断分布求积 / GARCH 1e7×2 参照)。

**结果(n=240、≥80% 功效的 βσ_W 区域)**:
| W 分布 | 可行区 | 备注 |
|---|---|---|
| Gaussian(管线校验 0.00% err) | βσ_W ≤ 2 | 最理想情形 |
| 截断 Student-t df=5 (10σ) | **仅 βσ_W=0.5**(βσ=1 时功效 14%) | 轻微重尾即崩 |
| 截断 Student-t df=3 | **NONE** | |
| crash 混合 (0.9N+0.1 负功 lump) | **NONE**(βσ=4 偏差 +4.7σ) | |
| GARCH(1,1)-t 事件聚合(最真实) | **NONE;参考值 1e7 样本自身不收敛**,偏差 +13~25σ | |

解析事实(写进脚本注释):**任何多项式左尾的 W(如未截断 t)⇒ E[e^(−βW)]=∞**,
Jarzynski 平均根本不存在 — B2 预注册必须包含 W 左尾诊断。偏差方向系统为正
(漏采稀有负功 ⇒ ΔF̂ 高估),与文献一致。

**S8 判定:B2 照原设计(对 FOMC/财报事件做裸 Jarzynski 指数平均)在统计上不可行,
除非实测功分布近高斯且 βσ_W ≲ 1 ——市场功分布几乎必然重尾(GARCH 行),故 B2 必须
重设计(块平均 protocol / 小功扇区积分 FT / 其他估计器)或降级。** A1+B2 的
"反 curve-fit 组合拳"因此断了一翼,plan v3.1 必须给 A1 配新的独立验证腿
(S3 玩具模型恢复 + B3 交叉)或接受降级。这个结论花费 $0、2 小时——三道闸的意义所在。
