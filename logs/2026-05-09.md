**B1 — Microstructure noise** (`ecomd/physics/integrator.py`)

  wasserstein, mmd, sinkhorn, hybrid}` with W2 multi-scale, Sinkhorn,
  MMD all implemented through `compute_loss()` dispatcher

**B3 — Discrete Gumbel regime** (`ecomd/models/regime_latent.py`)
- New `DiscreteRegimeGRU` class with K-state Gumbel-softmax:
  - `init_h` returns logits (n_states,)
  - `maybe_step` updates logits via GRU
  - `read(h)` produces d_regime embedding for read heads
- Refactored `RegimeGRU` to add identity `read(h)` for API parity
- `EcoMDSimulator.__init__` branches on `regime_discrete_enabled` flag
- Step function calls `regime_gru.read(h_regime_next)` before passing
  to gamma/T/kappa read heads
- 8 unit tests pass: validation, init_h shape, simplex output,
  schedule-respecting maybe_step, full simulator finite, default-off,
  combo stacking, reproducibility

**B4 — Power-law force tail** (`ecomd/models/potentials.py`)
- New `PowerLawExternalPotential` class:
  - V_ext(s) = w_mlp · MLP + w_pow · |s|^α/α
  - Sub-linear gradient at large |s| for α<2
  - eps clamp prevents singularity at s=0
- `EcoMDSimulator.__init__` branches on `power_law_external` flag
- 7 unit tests pass: validation, MLP-only equivalence at w_pow=0,
  sub-linear force property, simulator finite, combo stacking,
  default-off branches to ExternalPotential, on-flag branches to
  PowerLawExternalPotential
